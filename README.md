# Plainroot Studio

The public pages for Plainroot Studio's apps, served by GitHub Pages.

- `lexmio/support.html`: Lexmio support (English and Turkish)
- `lexmio/privacy.html`: Lexmio privacy policy (English and Turkish)

The pages are generated from `Site/` in the Lexmio project. Edit them there and copy them here, so the app's links and these pages stay in step.
